# `!!AE_SmallScripts` — конвенция

Папка под личные мелкие скрипты для After Effects.
Лаунчер: [`Small_Scripts_Panel.jsx`](Small_Scripts_Panel.jsx) — dockable ScriptUI Panel.
Сканирует папку, парсит шапку каждого скрипта, рендерит кнопку с описанием.

## Конвенция: `@ae-script` header

Каждый скрипт начинается с блока в формате YAML-like `key: value`:

```js
/* @ae-script
name:  Короткое имя для кнопки
desc:  Что скрипт делает. Одна-две фразы.
prep:  |
  - что выделить
  - что открыть
  - что должно быть на CTI
tags:  selection, layers
*/
```

### Правила

- Блок должен идти **первым** в файле (до любого кода).
- Стартует строго с `/* @ae-script` (пробел или перевод строки после, неважно).
- Закрывается обычным `*/`.
- Ключи: `name`, `desc`, `prep`, `tags` — остальные читаются, но в UI пока не рендерятся.
- **Многострочное значение** — `key: |`, дальше строки с **отступом минимум 2 пробела**:
  ```
  prep:  |
    - первая строка
    - вторая
  ```
- Однострочное — просто `key: value`. Лидирующие/трейлинговые пробелы trim'аются.
- JSDoc-стиль (`* name: ...` со звёздочкой) тоже работает — звёздочка снимается.
- Парсер читает только первые ~8KB файла. Шапка должна быть в начале.

### Что куда

| key   | назначение                                                           |
|-------|----------------------------------------------------------------------|
| name  | подпись кнопки в панели                                              |
| desc  | основное описание (видно в hover-tooltip)                            |
| prep  | что подготовить ДО запуска (выделение, CTI, активная компа, и т.д.)  |
| tags  | свободные теги через запятую (на будущее — для группировки/поиска)   |

### Шаблон нового скрипта

```js
/* @ae-script
name:  My Cool Action
desc:  Что делает.
prep:  |
  - что нужно сделать перед запуском
tags:  
*/

(function () {
    var comp = app.project.activeItem;
    if (!(comp instanceof CompItem)) {
        alert("Открой композицию.");
        return;
    }
    app.beginUndoGroup("My Cool Action");
    try {
        // ...
    } catch (e) {
        alert("Ошибка: " + e.toString());
    }
    app.endUndoGroup();
})();
```

## Workflow

1. Добавил/изменил скрипт в папке.
2. В панели — **Reload**. Без рестарта AE.
3. Скрипт без `@ae-script` шапки тоже появится — но кнопка будет с именем файла и tooltip-напоминанием.

## Установка лаунчера

Полная инструкция — в [README.ru.md](README.ru.md#установка). Коротко: `Small_Scripts_Panel.jsx`
кладётся (лучше симлинком, чтобы правки подхватывались сами) в `Support Files\Scripts\ScriptUI Panels`
каждой нужной версии AE. После рестарта AE — `Window > Small_Scripts_Panel.jsx`, задокать; при
первом запуске — **Folder...** и выбрать папку со скриптами.
