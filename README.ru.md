# AE Small Scripts

Докабельная панель для **After Effects**, которая превращает папку со скриптами ExtendScript
в столбик кнопок, и сами скрипты из этой папки: привязка 2D-слоёв к 3D с перспективным
масштабом, MoGraph-эффекторы для слоёв и текста, риг отстающих детей, нуль между двумя
родителями, сброс Scale шейп-слоёв и набор помощников для таймлайна и проекта.

## Панель

`Small_Scripts_Panel.jsx` сканирует одну папку и делает кнопку на каждый `.jsx` / `.js` в ней.

- Подпись кнопки и подсказка при наведении — что скрипт делает и что подготовить перед
  запуском — берутся из короткой шапки в начале скрипта (см. [Свои скрипты](#свои-скрипты)).
  Скрипт без шапки тоже получает кнопку — с именем файла.
- **Reload** — пересканировать папку без перезапуска AE: положил скрипт, нажал Reload.
- **Folder…** — выбрать папку со скриптами. Выбор хранится в настройках AE.
- **Open dir** — открыть папку в Проводнике.
- Сканируется только верхний уровень папки. Чтобы убрать скрипт из панели, переложи его в
  любую подпапку.

Работает задоканной (установка в *ScriptUI Panels*) или плавающей палитрой
(*File → Scripts → Run Script File…*).

## Скрипты

### 3D и камера

#### 📌 2D ↔ 3D below (Position)

`Pin_2D_layer_to_3D_below.jsx`

Прибивает выделенный 2D-слой к экранной позиции 3D-слоя, лежащего прямо под ним в стеке
слоёв. Выражение на Position проецирует Anchor Point 3D-слоя через активную камеру с помощью
`toComp()`. Сам слой остаётся 2D: режимы наложения, 2D-эффекты и порядок слоёв работают как
обычно. Scale, Rotation и Opacity не трогаются.

Это тумблер: повторный запуск на привязанном слое отвязывает его, запекая текущую позицию, —
слой остаётся ровно там, где стоял на этом кадре. Учитывает parent у 2D-слоя и Separate
Dimensions. Молчаливый: если слой не 2D или прямо под ним нет 3D-слоя, ничего не происходит.

**Перед запуском:** выделить 2D-слой, прямо под которым лежит 3D-слой (нуль, солид…). Чтобы
отвязать — выделить привязанный слой и встать на кадр, который нужно сохранить.

#### 📌 2D ↔ 3D below (Position + Scale)

`Pin_2D_layer_to_3D_below_scale.jsx`

Та же привязка, плюс Scale 2D-слоя следует за видимым через камеру размером 3D-слоя: наезд
камеры, её зум, движение слоя в глубину, Scale самого 3D-слоя и его родителей. Повороты
3D-слоя на размер не влияют. Кадр, на котором нажал, — кадр калибровки: на нём 2D-слой
сохраняет свой размер, а дальше растёт и сжимается пропорционально. Собственный Scale слоя,
включая ключи, умножается, а не затирается. Работает и без слоя камеры — через дефолтную
камеру композиции.

Видимый размер — меньшее сингулярное число экранного якобиана `toComp()` по трём локальным
осям 3D-слоя. Для слоя с равномерным Scale это ровно Scale · zoom / глубина — в любом месте
кадра и при любом повороте слоя. Вывод и отвергнутые варианты — в [NOTES.md](NOTES.md).

Тумблер: на слое, привязанном с Scale, — отвязывает, запекая Position и Scale; на слое,
привязанном кнопкой «(Position)», — докручивает Scale. Кнопка «(Position)» отвязывает оба.

**Перед запуском:** выделить 2D-слой над 3D-слоем и встать на кадр, где размер 2D-слоя
выставлен как надо.

#### 🔀 Blend parent (A ↔ B)

`Blend_parent_2_layers.jsx`

Создаёт 3D-нуль, который ведёт себя так, будто запаренчен сразу к двум 3D-слоям с весом
(на выражениях, не настоящий parent). При **Blend** = 0 нуль точно повторяет мировой трансформ
слоя A, при 1 — слоя B, между ними позиция и масштаб интерполируются линейно, поворот — по
кратчайшей дуге (slerp). Родители у A и B учитываются. Свои слои вешай на этот нуль
парентингом, как на обычного родителя. Цели можно перевыбрать в Layer Control
**Parent A** / **Parent B**.

**Перед запуском:** выделить ровно два 3D-слоя: первый выделенный — A (Blend 0), второй — B
(Blend 1). Созданный нуль самого ни к чему не парентить: его трансформ считается в мировых
координатах.

### Риги и движение

#### ⏳ Delay children (trail)

`Delay_children_trail.jsx`

Выделенный нуль остаётся родителем, но дети повторяют его анимацию с отставанием. Свои
трансформы и ключи детей не трогаются: выражения только компенсируют трансформ родителя на
дельту времени. Задержка = **Delay (frames)** на нуле × **Delay mult** на каждом ребёнке (по
умолчанию 1, 2, 3… сверху вниз — готовый каскад). Position компенсируется точно, через
`toWorld` / `fromWorld`; Rotation и Scale — покомпонентно, поэтому у 3D-нуля, крутящегося
сразу по нескольким осям, поворот приблизительный.

**Перед запуском:** выделить один анимированный нуль (возьмутся все его прямые дети) либо нуль
и нужных детей. Alt+клик по кнопке снимает выражения и слайдеры.

#### 🧲 MoGraph effector

`MoGraph_effector.jsx`

Plain Effector в духе MoGraph из Cinema 4D. Выделенные слои становятся клонами, над ними
создаётся эффектор — гайд-шейп с гизмо falloff'а и параметрами:

- Position X/Y/Z, Scale %, Rotation X/Y/Z, Opacity %;
- falloff Sphere / Box / Linear / Infinite с изингом рампы: Linear, Smooth и S-кривые разной
  крутизны со сдвигом к краю или к центру;
- Delay Off / Blend / Spring — отставание и пружина всего движения клона: его ключей, движения
  родителя и реакции на эффектор. Задержка одинаковая для всех клонов, falloff на неё не
  влияет.

Каждый клон получает вес **MG Weight** (0–100), считаемый от своей точки покоя. Сдвиг идёт
через Anchor Point, так что Position и ключи клона не трогаются.

Что делает кнопка, решает выделение:

- слои → новый эффектор с ними в роли клонов;
- эффектор + слои → слои добавляются к нему;
- только эффектор → обновить до текущей версии (новые контролы, выражения клонов);
- Alt+клик → снять выделенные клоны; если выделен эффектор — снять всех его клонов и удалить
  его.

#### 🔤 MoGraph text effector

`MoGraph_text_effector.jsx`

Тот же эффектор для текстового слоя. Клонами становятся буквы, слова или строки — меню
**Clone** на эффекторе, переключается вживую. Контролы те же, что у эффектора слоёв. На слой
ставятся три аниматора текста с Expression Selector'ами, исходный текст не трогается.
Раскладку букв кнопка меряет и запекает — поправил текст, шрифт или размер: выдели эффектор и
нажми снова.

**Перед запуском:** текстовый слой (или несколько) → создать; эффектор + текстовые слои →
добавить; только эффектор → перемерить; Alt+клик → снять.

### Слои и таймлайн

#### ✗ Deselect parented

`Deselect_parented.js` — снимает выделение со слоёв, у которых есть parent; выделенными
остаются только независимые.

#### Remove gaps between layers

`uplotnit_montazh.js` — сортирует выделенные слои по времени начала и сдвигает так, чтобы
каждый начинался ровно в конце предыдущего. Выделить два слоя или больше.

#### Fit comp duration to selected layer

`Fit_comp_duration_to_selected_layer.jsx` — подгоняет длину композиции так, чтобы она
заканчивалась вместе с выделенными слоями, с округлением вверх до целого кадра. Футаж с
длительностью (видео, аудио, прекомп) считается до конца источника, даже если слой обрезан;
стиллы, солиды, шейпы и текст — до своего out point. При нескольких слоях побеждает самый
поздний конец. Ещё скрипт пытается отзумить таймлайн на всю длину, но команды для этого AE
скриптам не даёт, так что эта часть ничего не делает (см. [NOTES.md](NOTES.md)).

#### Layer markers → Comp markers

`Layer_markers_2_Comp_markers.jsx` — копирует маркеры выделенного слоя в маркеры композиции на
те же таймкоды, с комментариями, chapter и URL. Выделить ровно один слой.

### Проект и футаж

#### InOut GAPЫ selected footages

`InOut_GAPS_select_footages.js` — раскладывает выделенные в Project футажи на один таймлайн по
**стартовому таймкоду источника**. Каждый клип заворачивается в свою композицию
(`WRP__<имя>`), обёртки встают в `SEQUENCE_byStartTC` на свои таймкоды, промежутки
заполняются: до 30 с — чёрным солидом с длиной промежутка в имени, длиннее — красным солидом
на 5 с с маркером длины. Всё складывается в папку `_WRAPPED_byStartTC`; в конце — отчёт о том,
из какого поля прочитан таймкод. Выделить два футажа или больше.

#### Comp per video layer

`precom_each_layer.js` — для композиции, выделенной в Project, создаёт отдельную композицию на
каждый слой с видеофутажем: размером с футаж и длиной с видимый кусок слоя, футаж сдвинут так,
что играет ровно этот кусок. Новые композиции складываются в папку с именем исходной, сама
она не меняется. Выделить ровно одну композицию в Project.

#### Paste image from clipboard

`paste_image_from_clipboard.jsx` — сохраняет картинку из буфера обмена в
`<папка проекта>/imgs_pasted/pasted_<timestamp>.png` и импортирует в бин `imgs_pasted`. Только
Windows (под капотом PowerShell). Проект должен быть сохранён, и должна быть включена
настройка *Allow Scripts to Write Files and Access Network*
(*Edit → Preferences → Scripting & Expressions*).

#### Rename Panel (open)

`Rename_Panel.jsx` — палитра утилит переименования: суффикс с именем папки для композиций,
Find / Replace и обрезка после первого совпадения — с выбором скоупа (выделение, выделенная
папка, весь проект) и фильтром «только композиции».

### Шейпы

#### Reset shape Scale → 100%

`Reset_shape_layer_scale.jsx` — сбрасывает Scale шейп-слоёв и всех групп внутри в 100%,
запекая масштаб в геометрию: пути, Size и Position прямоугольников, эллипсов и звёзд, толщину
и штрихи обводки, радиус Round Corners, точки градиента, трансформы вложенных групп и
Repeater. Визуально слой не меняется. Однородный статичный Scale запекается точно,
неоднородный — с предупреждением, анимированный остаётся как есть.

## Установка

1. Забрать файлы: `git clone https://github.com/Paradoximus/ae-small-scripts.git` или
   *Code → Download ZIP*.
2. Положить `Small_Scripts_Panel.jsx` в папку *ScriptUI Panels* каждой версии After Effects,
   которой пользуешься:
   - Windows: `C:\Program Files\Adobe\Adobe After Effects <версия>\Support Files\Scripts\ScriptUI Panels\`
   - macOS: `/Applications/Adobe After Effects <версия>/Scripts/ScriptUI Panels/`

   Симлинк лучше копии: тогда панель обновляется вместе с `git pull`. На Windows — в
   PowerShell от администратора (или с включённым Developer Mode):

   ```powershell
   $src = "D:\path\to\ae-small-scripts\Small_Scripts_Panel.jsx"   # путь к клону
   Get-ChildItem "C:\Program Files\Adobe" -Directory -Filter "Adobe After Effects*" | ForEach-Object {
       $dir = Join-Path $_.FullName "Support Files\Scripts\ScriptUI Panels"
       if (Test-Path $dir) {
           $dest = Join-Path $dir "Small_Scripts_Panel.jsx"
           if (Test-Path $dest) { Remove-Item $dest -Force }
           New-Item -ItemType SymbolicLink -Path $dest -Target $src | Out-Null
           "linked: $dest"
       }
   }
   ```

3. Перезапустить AE, открыть *Window → Small_Scripts_Panel.jsx* и задокать.
4. При первом запуске панель напишет «Папка не найдена». Нажать **Folder…** и выбрать папку
   клона. Выбор запоминается — для каждой версии AE отдельно.

## Свои скрипты

Положи `.jsx` или `.js` в папку и нажми **Reload**. В начале файла — шапка, из неё панель
собирает кнопку:

```js
/* @ae-script
name:  Подпись кнопки
desc:  Что делает скрипт. Видно в подсказке.
prep:  |
  - что выделить
  - что открыть
tags:  layers, timeline
*/

(function () {
    var comp = app.project.activeItem;
    if (!(comp instanceof CompItem)) { alert("Открой композицию."); return; }
    app.beginUndoGroup("Моё действие");
    // ...
    app.endUndoGroup();
})();
```

- Шапка идёт первой в файле; читаются только первые 8 КБ.
- Ключи: `name`, `desc`, `prep`, `tags`. Многострочное значение начинается с `key: |`, дальше
  строки с отступом минимум в два пробела.
- Полная спецификация — [README_convention.md](README_convention.md).

## Разработка

Сборки нет: скрипты — обычный ExtendScript (ES3) и запускаются как есть.

- `_dev/ae_stub_*.js` — node-стабы AE DOM под нетривиальные скрипты, например
  `node _dev/ae_stub_pin2d_scale.js`. Проходят ветки скрипта и проверяют синтаксис каждого
  выражения, которое он пишет. Стабы MoGraph, Blend parent и Pin 2D + Scale вдобавок исполняют
  сгенерированные выражения на модели трансформов слоёв AE (а для привязки — и камеры) и
  сверяют результат с ожидаемой математикой. Поведение в самом AE всё равно проверяется в AE.
- `_dev/hook_check.js` — проверка синтаксиса и шапки: `node _dev/hook_check.js --file <путь>`.
  Работает и как PostToolUse-хук Claude Code (читает JSON хука со stdin).
- [NOTES.md](NOTES.md) — рабочие заметки: математика выражений, отвергнутые варианты, грабли
  скриптинга AE.
- [CLAUDE.md](CLAUDE.md) — конвенции и известные грабли, которые Claude Code подгружает в
  каждую сессию.

Стабам нужен только Node.js, npm-зависимостей нет.

## Совместимость

Пишется и используется на Windows в After Effects 2025, 2026 и Beta. На macOS не проверялось,
*Paste image from clipboard* — только Windows. Выражения рассчитаны на JavaScript-движок
выражений, который в AE стоит по умолчанию.
