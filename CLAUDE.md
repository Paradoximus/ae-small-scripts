# !!AE_SmallScripts — контекст проекта

Мелкие скрипты для After Effects (ExtendScript, ES3-ish) + панель-лаунчер к ним. Не npm-проект.
Git-репо, **публичный**: https://github.com/Paradoximus/ae-small-scripts (ветка `main`).

| что | где |
|-----|-----|
| скрипты (кнопки в панели) | корень, `*.jsx` / `*.js` |

## Публичный репозиторий

- Всё, что коммитится, видят все. В коде, `NOTES.md` и README — без имён, почты, путей к
  личным папкам и названий рабочих проектов. Не относящееся к AE-скриптам — в
  `NOTES.private.md`.
- Новая кнопка или заметная правка поведения → обновить шапку **и** строку каталога в
  обоих README (EN + RU), иначе описание на GitHub разъедется с панелью.
- Коммит и push — только по просьбе.

## Шапка `@ae-script` — обязательна, первым блоком в файле

```js
/* @ae-script
name:  Короткое имя для кнопки
desc:  Что делает. Одна-две фразы, в одну строку.
prep:  |
  - что выделить
  - что открыть
tags:  selection, layers
*/
```

Ключи `name`, `desc`, `prep`, `tags` — все четыре. Многострочное значение: `key: |`,
дальше строки с отступом >= 2 пробела. Парсер читает первые 8 КБ файла.

## Идиома дома

- Всё тело — IIFE: `(function () { ... })();`
- Гарды по порядку: `app.project` → `activeItem instanceof CompItem` → `comp.selectedLayers.length`
- `app.beginUndoGroup(...)` / `app.endUndoGroup()` **оборачивают** правки, а не идут после них.
  Пустая группа undo-шага не создаёт — открывать можно не глядя.
- Свойства — по `matchName` (`"ADBE Transform Group"`, `"ADBE Position"`), не по локализованному имени.
- Язык комментариев и сообщений — русский.
- Молчаливость по умолчанию **не** предполагается: обычно `alert` на невалидный ввод. Если
  в задаче сказано «просто ничего не делать» — тогда ни одного `alert`, тихий `return`.

## Грабли, на которые уже наступали

- **Массивы в выражениях складываются через `add()` / `sub()`**, не через `+` — в JS-движке
  AE `+` на массивах даёт склейку строк.
- **`toWorld` vs `toComp`**: `toComp` гонит точку через активную камеру (экранные координаты),
  `toWorld` даёт мировые. Перепутать — тихо получить мусор. Подробности в `NOTES.md`.
- **Position 2D-слоя двумерна.** Вернуть в выражении 3 компоненты = ошибка
  «expression result must be of dimension 2, not 3».
- **Position живёт в системе координат родителя.** Слой с parent'ом требует
  `if (hasParent) p = parent.fromComp(p)`.
- У камер и светов нет `AVLayer.threeDLayer` (вернёт `undefined`) и нет `ADBE Effect Parade`.
- `dimensionsSeparated` — отдельная ветка: выражения идут на `ADBE Position_0` / `_1`
  и каждое отдаёт скаляр.
- **Временный слой сдвигает индексы.** `comp.layers.add*` встаёт в index 1, у всех слоёв
  index +1. Списки слоёв дедуплицировать по самому объекту, не по `index`; `Layer Control`
  ставить, когда временного слоя уже нет.

**Перед тем как писать скрипт с выражениями — грепнуть `NOTES.md`** по теме (`toComp`,
`fromWorld`, `dimensionsSeparated`). Там лежат разборы, которые из кода не выводятся.
Читать `NOTES.md` целиком не надо, он длинный — только релевантный раздел.

## Инструменты

- **`node --check` не читает `.jsx`** (ERR_UNKNOWN_FILE_EXTENSION). Проверять через
  `new vm.Script(src)` или копией в `.js`.
- Синтаксис + шапку после каждой записи автоматически проверяет PostToolUse-хук
  `_dev/hook_check.js` (прописан в `.claude/settings.local.json`). Руками:
  `node _dev/hook_check.js --file <файл>`.
- Логику AE-скрипта удобно гонять на node-стабе AE DOM: примеры — `_dev/ae_stub_pin2d.js`,
  `_dev/ae_stub_expr_dump.js`. Новый скрипт нетривиальнее десяти строк — сделать стаб.
  Стаб проверяет ветвление и синтаксис генерируемых выражений, но **не** семантику AE
  в рантайме: это только в самом AE. Исключение — математика выражений: в
  `_dev/ae_stub_mograph.js` сгенерированные выражения исполняются на 2D-модели трансформа
  AE (`world = Parent·(pos + R·S·(pt − anchor))`) — образец, если скрипт что-то считает.
  Для текста — `_dev/ae_stub_mograph_text.js`: модель шрифта и раскладки + эмуляция того,
  как AE применяет аниматоры текста к буквам.
- **Файлы с бэкслешами (регекспы, escape-последовательности) писать инструментом Write,
  а не bash-heredoc**: heredoc на этой машине съедает один слеш из `\\`, ломая
  `/\\/g` в `/\/g`. Напарывались дважды.
